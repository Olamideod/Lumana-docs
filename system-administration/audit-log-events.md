# Audit log events

This page lists every event Lumana tracks in the audit log. Use it to identify what an event in your log means or to understand what actions are recorded across your organization.

{% hint style="info" %}
This list reflects the current version of Lumana. It is updated as the product evolves. If you see an event in your audit log that doesn't appear here, then the product has been updated since this page was last published.
{% endhint %}

You can also search for any event directly in the product. Select the **Event** filter on the Audit logs page and use the search field to find a specific event by name.
