# Available permissions

This page lists every permission category in Lumana and what each option allows. Use it when [setting access rights for a permission group](manage-users-and-permissions.md#set-access-rights).

**Security roles**: [PLACEHOLDER — SME answer needed: What does Security roles enable?]

## Location

Location permissions control what users can do with your organisation's physical sites.

| Permission | What it allows |
|---|---|
| Read | View the location |
| Create | Add new locations |
| Edit | Update location details |
| Delete | Remove a location |

## Core

Core permissions control access to your Core devices.

| Permission | What it allows |
|---|---|
| Read | View the Core device |
| Create | Add new Core devices |
| Edit | Update Core device settings |
| Restart | Restart the Core device remotely |
| Delete | Remove a Core device |

## Camera

Camera permissions control what users can do with individual cameras.

| Permission | What it allows |
|---|---|
| Read | View the camera in the system |
| Create | Add new cameras |
| Live View | Watch the camera's live feed |
| Share live view | Share a live feed link with others |
| Playback | Review recorded footage |
| Share playback | Share recorded footage with others |
| Push to talk | Use two-way audio through the camera |
| Edit | Update camera settings |
| Delete | Remove a camera |

## Organization

Organisation permissions control access to system-wide settings and administrative features.

| Permission | What it allows |
|---|---|
| Edit | Update organisation settings |
| Users access | View and manage users |
| Groups access | View and manage permission groups |
| Sharing access | View and manage shared content |
| Audit logs | Access audit log records |
| Alert notification logs | Access alert notification records |
| API keys | View and manage API keys |
| Permissions | View and manage permission groups |
| Login firewall | Configure login firewall rules |
| Delete | Delete the organisation |
| Monitoring | Access monitoring tools |
| Integrations | View and manage third-party integrations |
| OAuth providers | View and manage OAuth provider settings |

## Invites

Invite permissions control who can send and manage user invitations.

| Permission | What it allows |
|---|---|
| Create | Send invitations to new users |
| Edit | Modify pending invitations |
| Delete | Cancel pending invitations |

## Archive

Archive permissions control access to recorded and saved footage.

| Permission | What it allows |
|---|---|
| Read | View archived footage |
| Create | Archive footage |
| Share | Share an archive with others |
| Revoke shared archive | Remove access to a shared archive |
| Download | Download archived footage |
| Delete | Delete archives |

## Wall

Wall permissions control access to the video wall feature.

| Permission | What it allows |
|---|---|
| Read | View video walls |
| Quick live view | Open a live view directly from a wall |
| Create | Create new video walls |
| Edit | Edit existing video walls |
| Delete | Delete video walls |

| Permission | What it allows |
|---|---|
| Read | View organisation database records |
| People directory | Access the people directory |
| Doors directory | Access the doors directory |
| Vehicle directory | Access the vehicle directory |
| Event tags | Access event tags |
| Entrances directory | Access the entrances directory |
| Custom objects directory | Access the custom objects directory |
| Shelves directory | Access the shelves directory |

## Event

Event permissions control who can view and manage events in the system.

| Permission | What it allows |
|---|---|
| Read | View events |
| Create | Create new events |
| Edit | Edit existing events |
| Delete | Delete events |

## Alert

Alert permissions control access to alert monitoring and management.

| Permission | What it allows |
|---|---|
| Monitoring | Monitor active alerts |
| Delete | Delete alert records |
| Acknowledge alert | Mark alerts as acknowledged |

| Alert groups | View and manage alert groups |

## Notification

Notification permissions control which system notifications users receive.

| Permission | What it allows |
|---|---|
| SMS rate limit reached | Receive a notification when the SMS limit is reached |
| HTTP Requests errors | Receive a notification when HTTP request errors occur |

| Permission | What it allows |
