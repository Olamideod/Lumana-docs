# Create links between cameras

On-image shortcuts between related cameras are documented under [Create camera shortcuts](create-camera-shortcuts.md). Use that guide to place links in **Edit camera** so operators can jump between live views.

If you need a workflow that is not covered there, contact [support@lumana.ai](mailto:support@lumana.ai).
