# Free text search

Use natural language on **Search** to find people, vehicles, and other objects across your cameras. In the product UI the page title is usually **Text search**, and the **Free text** control holds your query. This path helps when scenes or attributes are harder to capture with fixed filters alone.

## Prerequisites

Make sure you can open **Search** and access the cameras you want to review. If you already know the time range or locations you want to search, then keep those details ready so you can narrow the results faster.

## Example search

Free text search works well when you need to describe a scene in plain language instead of selecting only predefined filters.

For example, search for a person carrying a box through a door. You can then narrow the results to specific doors, entry points, or other camera groups.

## Start a free text search

Switch from classic search to **Text search**, set time range and cameras, then type a natural-language query.

1. Open **Search**.

   In the left sidebar, select **Search** if it is not already selected. You see classic search: category and precision controls, **Clips** and **Objects**, and **Switch to text search** in the header.

    <div align="center" data-with-frame="true"><img src="../.gitbook/assets/databases-analytics-and-search/free-text-search-start-screen.png" alt="" width="563"></div>

2. Select **Switch to text search**.

   The **Text search** page loads (**Search** and **Text search** in the breadcrumbs). To return to structured filters, select **Switch to classic search**. The bar shows the text field, a time range such as **Last 3 Days**, **Cameras**, and **Clips** / **Objects** (for example **Objects** selected). Until you finish setup, the page can show a prompt to choose time range, cameras, and filter.

    <div align="center" data-with-frame="true"><img src="../.gitbook/assets/databases-analytics-and-search/free-text-search-text-search-screen.png" alt="" width="563"></div>

3. Select **Cameras**.

   In **Choose cameras up to 100**, use **Search cameras and locations** if you need to narrow the list. Expand a location, select the cameras you want (you can pick up to 100), then select **Select**. The footer shows how many cameras you chose (for example **Selected 2 out of 100**).

    <div align="center" data-with-frame="true"><img src="../.gitbook/assets/databases-analytics-and-search/free-text-search-camera-selection-dialog.png" alt="" width="563"></div>

4. Enter a description in the search field, then run the search.

   For example, type `A person in black walking` and use the search control next to the field. With **Objects** selected, matching detections appear in a grid with timestamps and camera names; switch to **Clips** when you want clip-based results instead.

    <div align="center" data-with-frame="true"><img src="../.gitbook/assets/databases-analytics-and-search/free-text-search-results-example.png" alt="" width="563"></div>
