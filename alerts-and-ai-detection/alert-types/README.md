# Alert types

Alert types define the conditions Lumana monitors on your cameras. Each type has a pre-built template that you configure when creating an alert. The types are organised into categories based on what they detect, from security threats and identity recognition to device status and compliance monitoring.

Select a category below to browse the alert types it contains and learn how to configure each one.
